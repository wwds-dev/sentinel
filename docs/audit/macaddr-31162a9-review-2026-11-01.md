## Report (verbatim)

Review of 31162a9 (claude/macaddr-p32). Playbook `docs/playbooks/code-reviewer.md` is `status: current`, last reviewed 2026-10-14, so it is not stale. I ran `pytest tests/test_macaddr.py -q` and all 115 tests passed. I edited nothing.

**No P1 or P2 findings.**

**P3-1: the message can be wrong when the two reads disagree.** `agents/vpn_agent/services/macaddr.py:175-180` and the call sites at `:408-410`, `:472-474` and `:480-482`. `get_interface` reads the listing once, and `_missing_interface` reads it again from scratch.
- If the first read fails (for example a `networksetup` timeout) and the second succeeds and finds the device, `read_interface` returns `(iface, "")`. The user is told "No such interface: en5" about a device that exists, which is the exact message this commit set out to remove.
- The reverse case (first read misses, second fails) gives "Could not read…", which is harmless.
- Either way it is still a refusal, so nothing changes. The failure path also starts a second subprocess.
- Fix: call `read_interface(device)` once at the top of each function and branch on `(iface, error)`. That removes both the race and the extra read.

**P3-2: a weak test seam.** `tests/test_macaddr.py:779-802`. The tests replace `get_interface` and `read_interface` independently, so they never run a failing `run(["networksetup", …])` through the real `list_interfaces_checked` → `_missing_interface` path. They also cannot show the disagreement in P3-1.
- They do pin the wording, the branch and `root["calls"] == []`. Deleting the `if error:` branch or changing the text would fail them.
- Fix: add one case that stubs `macaddr.run` to return `(False, "timed out aa:bb:cc:dd:ee:ff")`. Assert the message carries "Could not read" and "<address>" and contains no MAC.

**Checks that passed:**
- **Redaction:** the error is put through `redact_addresses` before it is cut to 200 characters (`:126`), so no address can leak through a truncation.
- **State:** all three refusal paths return before any `run_argv_as_root` call or record write.
- **Tier C rules:** no `shell=True`, argv lists only, and the change fails closed.
