  - `sentinel/` — security/investigation command centre; own repo. It began as a fork
    of `sentinel_ai` and has diverged further than `sentinel_ai` on the agents they still
    share (`osint_agent.py`, `wifi_agent.py`, `vpn_agent.py`, `manager_agent.py` all
    differ — Sentinel's versions are the more developed ones). `bug_bounty_agent.py` and
    `osint_heavy_agent.py` are still byte-identical to `sentinel_ai`'s copies;
    `chat_agent.py` is identical across `sentinel_ai`, `sentinel` and `imprint`.
    `sentinel` has no separate `router_agent.py` — its auto-route logic is inlined in
    `main.py` instead.
    **"Sentinel" is the name at every level.** The app took it at the V2 release
    (2026-09-12); the folder (`sentinel_fork`), the repo and the remote
    (`sentinel-ai-fork`) followed on 2026-10-06. GitHub redirects the old remote URL, so
    an old clone keeps working, but nothing should be written with the old names again.
    `scripts/install_app.sh` installs
    `/Applications/Sentinel.app`, which runs this project's own `main.py` through its
    `.venv` so code edits are live on the next launch with no rebuild. The PyInstaller
    build does still exist (`Sentinel.spec`, `scripts/build_app.sh`) and is the way to
    hand someone a copy that needs no checkout; it installs only with `--install`.
    Both install scripts also `rm -rf` the legacy
    `/Applications/Sentinel Fork.app`, which is why that bundle is gone.
    **Every app is called by its own name everywhere — never `python`.** That covers
    Activity Monitor, the Dock, Cmd-Tab, Force Quit and the menu bar. It is a standing
    rule for every app in this workspace, including new ones, not a trade-off to
    document. macOS names a process after the path of the executable it is *running*,
    and never re-reads it, so **a live launcher must not exec `.venv/bin/python`**. A
    `fork()` + exec shim and a plain `exec` both make the process `python`, and nothing
    inside the app can repair the Dock, Cmd-Tab, Force Quit or Activity Monitor name
    afterwards. A shim also left a second, windowless Dock tile behind. The answer is
    `scripts/app_launcher.c` (2026-10-07), shared byte for byte by `sentinel/` and
    `imprint/` — a test in each fails if the copies differ. It is the bundle's
    executable, named after the app, and it links the libpython the venv was made from
    and runs `main.py` **in-process** with the venv's packages. It also sets
    `sys.executable` to itself, so workers started with `sys.executable` (Imprint's
    narrator) carry the app's name too; given Python's own arguments (`-m`, `-c`, `-u`…)
    it behaves as the venv's interpreter. Frozen builds already satisfy the rule — every
    other app here is one. Consequences: re-run `install_app.sh` after rebuilding a venv
    on a new Python **minor** version (the rpath goes through uv's minor-version
    directory, so patch upgrades need nothing), and the install scripts quit a running
    copy through `-[NSRunningApplication terminate]`, never `pkill`, because `closeEvent`
    is where state is saved. The history: Imprint's AppleScript applet blocked in `do
    shell script` for the GUI's lifetime, so Activity Monitor showed it *Not Responding*
    the whole time it ran; Sentinel's `thin_launcher.c` shim (2026-09-15 → 2026-10-07)
    and Imprint's one day on it showed `python`. `ui/app_identity.py` (in both, kept
    identical apart from the name) is now only for a terminal `python main.py`: it
    writes `CFBundleName` before `QApplication()` so the app menu is titled correctly,
    and sets the Dock icon with `-[NSApplication setApplicationIconImage:]` after it —
    `QApplication.setWindowIcon` does not touch the Dock icon on macOS. Renaming an app
    Lab Hub launches means **rebuilding Lab Hub**: its registry is compiled into its own
    bundle, so until then the tile reads *Source only* and looks like a fault in the
    renamed app rather than a stale hub.
    **Sentinel chooses models on value, never on novelty** (2026-10-07, the user's
    rule): a request is classified by kind of work, every usable model is looked
    up on the public LMArena leaderboard for that kind, and the cheapest model
    rated within 20 points of the best wins (`services/benchmarks.py`,
    `route_request`); each agent's BEST FIT is the same assessment, re-derived,
    never hand-pinned to the newest release. An unknown or zero price is never
    cheap, and an unrated model never beats rated ones. Do not reintroduce
    "newer wins" tie-breaks or successor rules. Hugging Face's dataset query
    endpoint for the ratings answered "index is loading" for minutes; the row
    pager works but returns 429 after ~40 quick anonymous requests, so it is
    paced at 1 s and falls back to `config/lmarena_snapshot.json`.
    **That module is copied into `imprint`** (2026-10-08), whose text BEST FIT now
    follows the same rule at the user's choice — the cheapest model rated within
    20 points of the best available wins, an unrated one is not chosen while a
    rated one can be — expressed as a score so Imprint keeps its one-point-lead
    and never-auto-switch rules; media and unrated text keep Imprint's agent
    blend. `imprint/tests/test_benchmarks_drift.py`
    fails when the copies diverge; Imprint's may differ only in its docstring, its
    User-Agent and one marked *Imprint only* block (`best_rating`). Port any other
    change to both in the same session. Sentinel has no mirror test yet.
    **All eight agents live in `sentinel/agents/`** (Sentry, added 2026-09-28, is the
    eighth). Since 2026-10-09 every one except `bug_spray` is tracked in Sentinel's own
    repo; `agents/bug_spray` is the only nested repo left, a git submodule
    (`wwds-dev/bug_spray`). None of them gets a Lab Hub tile. Two have a
    standalone app of their own, and neither is installed any more (the bundles were
    pruned on 2026-09-12; both rebuild from their own `build_app.sh`):
    - `agents/bug_spray/` — "Bug Spray", the `bug_bounty` agent's triage app.
    - `agents/vpn_agent/` — "Tunnel", the `vpn` agent's app: *runs* a VPN (monitor, kill
      switch) and *builds* the server behind it (WireGuard + OpenVPN/443), plus a Privacy
      tab. Worked on outside this workspace — leave its source alone unless asked.
    The other five (Chat, Trace/`osint`, Bloodhound/`osint_heavy`, Beacon/`wifi`,
    Forge/`manager`) have no standalone app at all.
